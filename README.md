# ليل — Layl

تطبيق iOS أصلي مبني بـSwiftUI، بواجهة عربية/إنجليزية وتجربة تصفح مستوحاة من خدمات المشاهدة، يعرض كتالوجًا صغيرًا من الأفلام المتاحة قانونيًا للتشغيل داخل التطبيق، ويتيح تصفح بيانات عالمية للأفلام والمسلسلات والأنمي عبر TMDB.

## ما الذي يفعله الكتالوج العالمي؟

TMDB يوفّر بيانات العناوين والملصقات والصور والبحث والرائج للأفلام والمسلسلات، كما يوفّر تفاصيل إضافية مثل التصنيفات والمدة وعدد مواسم المسلسلات. لا يوفّر ملفات فيديو أو حقوق تشغيلها. يُستكشف الأنمي بتصفية الرسوم المتحركة ذات اللغة الأصلية اليابانية؛ وهذا تصنيف تقريبي لأن TMDB لا يضمن حقلًا مستقلًا للأنمي. لذلك تعمل داخل Layl فقط الأعمال الموجودة في كتالوجه القانوني المحلي؛ أما نتائج TMDB فهي للاستكشاف والمعلومات، ويقود زر التفاصيل إلى صفحة العمل في TMDB.

استخدام TMDB مجاني للمشاريع غير التجارية وفق شروطه. أنشئ API Read Access Token من [إعدادات API في TMDB](https://www.themoviedb.org/settings/api)، ثم أدخله داخل التطبيق من **حسابي ← الإعدادات ← TMDB · API**. يُحفظ الرمز في Keychain على الجهاز. لا تضع الرمز في ملفات المشروع أو المستودع. الاستخدام يتطلب اتصال إنترنت.

يظهر الشعار ونص الإسناد داخل التطبيق كما تطلب [إرشادات TMDB الرسمية](https://www.themoviedb.org/about/logos-attribution): “This product uses the TMDB API but is not endorsed or certified by TMDB.”

## تشغيل التطبيق

- يتطلب المشروع macOS وXcode 15 أو أحدث، وiOS 17 أو أحدث.
- افتح `Layl.xcodeproj` في Xcode، واختر مخطط **Layl** ومحاكي iPhone أو iPad، ثم اضغط **Run**.
- أو نفّذ على Mac:

```bash
xcodebuild -project Layl.xcodeproj -scheme Layl \
  -destination 'platform=iOS Simulator,name=iPhone 16' build
```

إذا لم يتوفر هذا المحاكي، استخدم `xcrun simctl list devices available` لاختيار اسم مثبت. لا يتوفر بناء iOS على Linux؛ يلزم Xcode/macOS للتحقق من نجاح التجميع وتشغيل المحاكي.

## المقاسات والميزات

تتكيّف الواجهة مع iPhone وiPad والاتجاه الأفقي، وتوفّر إعدادًا لتغيير كثافة الشاشة. ملفات المستخدمين والمفضلة وتقدّم المشاهدة والإعدادات المحلية تُحفظ على الجهاز. نتائج البحث العالمية مخفية في ملف الأطفال لأن TMDB لا يوفّر تصنيفًا عمريًا موثوقًا لكل عنوان.

يمكن إضافة مصدر بيانات مخصص عبر HTTPS من الحساب. تحفظ مفاتيحه في Keychain، ولا تسمح إعدادات التطبيق باتصالات HTTP غير الآمنة. الروابط المباشرة للفيديو تعمل فقط إن كانت HTTPS ورابط ملف فيديو مباشر.

## خصوصية وحقوق

لا تُرسل بيانات الملفات الشخصية أو التقدّم إلى TMDB. عند استخدام الكتالوج، يرسل التطبيق طلبات بيانات TMDB باستخدام الرمز والبحث باللغة التي اختارها المستخدم. بيانات TMDB وصوره ليست ترخيصًا لمشاهدة الأعمال.

أعمال التشغيل المحلية مفتوحة الترخيص أو ضمن الملك العام، وتعرض صفحات التفاصيل مصادرها وشروطها. أصول TMDB الرسمية موجودة في `Layl/Assets.xcassets/TMDBLogo.imageset/`.

## ملفات مهمة

- `Layl/Model/` — النماذج والكتالوج وحالة التطبيق.
- `Layl/Services/` — TMDB وKeychain ومصادر API المخصصة.
- `Layl/Views/` — واجهات التطبيق.
- `Layl/Design/LayoutMetrics.swift` — قواعد الاستجابة لمقاسات الشاشة.
- `scripts/generate_xcodeproj.py` — مولّد ملف مشروع Xcode من ملفات Swift.

بعد إضافة أو إزالة ملف Swift، حدّث قائمة الملفات في `scripts/generate_xcodeproj.py` ثم نفّذ:

```bash
python3 scripts/generate_xcodeproj.py
```
